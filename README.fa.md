# 🐔 شبیه‌ساز بازی Farm Frenzy 2

> یک بازی مدیریت مزرعه و استراتژی نوشته‌شده با جاوا، به‌عنوان پروژه نهایی درس **برنامه‌سازی پیشرفته** دانشگاه اصفهان.

---

## 📖 معرفی پروژه

**Farm Frenzy 2** یک بازی دوبعدی از سبک استراتژی و مدیریت زمان است که در آن بازیکن یک مزرعه را مدیریت می‌کند، حیوانات اهلی پرورش می‌دهد، مواد خام را با ماشین‌آلات فرآوری کرده و محصولات را می‌فروشد. بازی روی یک **گرید ۵×۶** پیاده‌سازی شده و از **معماری MVC**، **چندرشته‌ای**، **پایگاه داده MySQL** و **JavaFX** استفاده می‌کند.

---

## ✨ امکانات اصلی

### 🐄 سیستم حیوانات (شی‌گرایی + ارث‌بری)
- **حیوانات اهلی:** مرغ، گاو، شترمرغ (تولید تخم‌مرغ، شیر، پر)
- **حیوانات کمکی:** سگ (محافظت در برابر حیوانات وحشی)، گربه (جمع‌آوری محصولات)
- **حیوانات وحشی:** پاندا (حمله به حیوانات مزرعه، قابل اسارت و فروش)

### 🏭 زنجیره تولید (ماشین‌آلات)
| دستگاه | ورودی | خروجی |
|--------|-------|-------|
| دستگاه پودر تخم‌مرغ | تخم‌مرغ | پودر تخم‌مرغ |
| نانوایی | پودر تخم‌مرغ | نان |
| دستگاه کره‌سازی | شیر | کره |
| دستگاه نخ‌ریسی | پر | نخ |
| دستگاه پارچه‌بافی | نخ + رنگ | پارچه |
| دستگاه خیاطی | پارچه + ربان + دکمه | لباس |

### 📦 مدیریت منابع
- **انبار** با ظرفیت محدود (قابل ارتقا)
- **چاه آب** برای کاشت چمن (با زمان انتظار)
- **ماشین** برای فروش محصولات به شهر (با شبیه‌سازی زمان سفر)
- **هواپیما** برای سفارش مواد اولیه از شهر (با شبیه‌سازی زمان پرواز)

### 🎯 پیشرفت بازی
- هر مرحله اهداف مشخصی دارد (مثلاً کسب X سکه، تولید Y محصول)
- چالش‌های زمان‌دار
- سیستم ستاره‌دهی بر اساس عملکرد
- ذخیره‌سازی پیشرفت در **پایگاه داده MySQL**

### 🧵 چندرشته‌ای و همزمانی
- مدیریت تردها با `ExecutorService`
- به‌روزرسانی UI از تردهای فرعی با `Platform.runLater()`
- استفاده از `synchronized` برای منابع مشترک (انبار، سکه، وضعیت حیوانات)
- قابلیت **توقف و ادامه** تمام تردها (ویژگی مکث بازی)

## 🚀 نحوه اجرا

### پیش‌نیازها
- JDK 17 یا بالاتر
- MySQL Server
- IntelliJ IDEA (یا هر IDE جاوا)

### مراحل
1. کلون کردن ریپازیتوری:
   ```bash
   git clone https://github.com/Asadix85/Farm-Frenzy-Java.git
وارد کردن به‌عنوان پروژه Maven در IntelliJ.

اجرای اسکریپت‌های SQL در پوشه /database برای ساخت جداول.

تنظیم اطلاعات اتصال دیتابیس در application.properties.

اجرای Main.java (MVC)

src/main/java/com/example/farm/
├── model/               // موجودیت‌ها (حیوان، محصول، ماشین، ...)
│   ├── animal/
│   ├── product/
│   ├── machine/
│   └── building/
├── controller/          // منطق بازی، مدیریت تردها
├── view/                // صفحات UI با JavaFX
├── repository/          // الیه دسترسی به دیتابیس (JDBC)
├── exception/           // استثناهای اختصاصی
├── util/                // ابزارهای کمکی
└── Main.java            // نقطه ورود برنامه
